# DéLa Já — The Next 100 Must-Haves

A prioritized, research-backed roadmap. Synthesized from a 7-agent research swarm
(competitor teardown, photo-pipeline, architecture, audience/virality, conversion,
"what women want," and a premium-DTC UX gap audit) plus the UX/motion deep-research.

Legend: ✅ done · 🛠 in progress · ☐ next

> **The single biggest lever** remains **real photos in the live preview** (#41–48).
> Nothing else moves the needle as much. Everything below assumes we get there.

### Recommended build order (waves)
- **Wave 1 (done):** cart + free-shipping + gift options + add-to-cart everywhere.
- **Wave 2:** reviews/ratings + trust badges + search + sort/filter + PDP richness.
- **Wave 3:** real-photo layer pipeline (unblock #43) — the visual leap.
- **Wave 4:** scent quiz + bundles + add-on upsells + email/SMS capture.
- **Wave 5:** real checkout + express pay + accounts + loyalty.
- **Wave 6:** kiosk lockdown + party booking/QR.
